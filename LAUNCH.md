# Launch

**Live:** https://theguysaccount.github.io/speed-run-heaven-civic-game/ (indexed; launched 2026-11-22).
**Production domain:** set by the domain rollout session. Exact DNS records and the one setting (`SITE_URL`) are in [OPERATIONS.md](OPERATIONS.md), key 1.

## Already running (machine channels)

- **Search.** Sitemap; robots.txt; a canonical address on every page; `VideoGame`, `FAQPage` and breadcrumb structured data. Open Graph and Twitter cards use a 1200×630 image.
- **IndexNow.** Every deploy pings it.
- **Host root.** The account's root `robots.txt` lists this site's sitemap. It is rebuilt daily.
- **Guide page.** It answers what people search for: how to play, how long a run takes, every upgrade's cost, and the fastest routes. The route times are computed from the game's rules on every build.
- **Share loop.** A finish-time card drawn on the device (native share sheet, PNG download, or copy link). The challenge link shows the next player the time to beat.
- **Embed.** A copy-paste iframe snippet on the About page.
- **GitHub.** Repo description, topics and README.

### Drafts

**r/incremental_games (title):** "Speed Run Heaven: a 20-minute incremental about building public AI the accountable way (free, no account, works on phones)"
> I made a short incremental with a run clock. You start as one citizen. You build nine engines, from texting a friend to a public Robot Corps, and enshrine six guarantees that multiply everything (receipts, public code, human appeal…). You finish when the country's "Heaven score" is measured. A full run takes about 20 minutes. Routed runs take under 10. When you finish you get a card with your time and a link that dares a friend to beat it. It's fiction, nonpartisan, and saves locally. Feedback on pacing is very welcome, especially where you stalled.

**Show HN:** "Show HN: Speed Run Heaven – an incremental game where you speedrun accountable public AI"
> A free browser idle game. The loop is the argument: legitimacy unlocks coordination, public AI lowers cognitive costs, robots lower material costs, and shared ownership turns the gain into time. Static site, React prerendered at build time, no server or cookies. The guide's speedrun table is generated by a scripted player that runs on the game's own rules at every build.

**itch.io page blurb:** "One citizen. One mandate. An automated future that belongs to everyone. Click, build nine engines, enshrine six guarantees and race the clock to Heaven. About 20 minutes. Each replay is 25% faster. A work of fiction."
